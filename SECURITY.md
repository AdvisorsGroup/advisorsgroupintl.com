# Security policy

This is a public, static website repository. Do not place credentials, API
tokens, authentication material, private certificates, or customer data in the
repository, its issues, pull requests, or commit messages.

Public browser configuration—such as the Cloudflare Turnstile site key and the
public contact-form endpoint—is intentionally visible. Server-side secrets must
remain in the service that processes the request.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Contact a
repository administrator privately with the affected URL, a concise description,
and steps to reproduce. Administrators should coordinate remediation before any
public disclosure.
